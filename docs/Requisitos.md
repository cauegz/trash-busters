# Requisitos do sistema

## 1. Funcionais
- O sistema deve permitir que o **usuário** se registre e faça login
- O sistema deve permitir que o **usuário** envie uma foto de um **lixo** 
jogado na rua
- O sistema deve detectar se a imagem é um **lixo** ou não
- O sistema deve retornar para o **usuário** a **quantidade de pontos de dano** 
que ele vai dar no **boss**, com base na **severidade do lixo**
- O sistema deve ter 15 **bosses**, um para cada **bairro de canoas**, cada um 
com uma determinada quantidade de **pontos de vida**
- O sistema deve permitir colaboração entre pessoas do mesmo **bairro** de 
canoas, juntando a quantidade de dano de cada **usuário** e diminuindo a vida 
do **boss**

## 2. Não Funcionais
- O sistema deve ter segunrança no login, não permitindo que entrem no sistema 
a partir de contas de outros **usuários**
- O sistema deve responder para o usuário o feedback do dano em, no máximo, 
**10 segundos**
